# Chicken Farming Ecommerce WordPress Project

## Project Overview
This project is developing a lightweight, responsive WordPress-based ecommerce website for selling chicken farming supplies and equipment. The site will serve as an MVP (Minimum Viable Product) focusing on simplicity and essential functionality before later iterations add more complex features.

## Business Focus
The ecommerce site specializes in products for chicken farmers, particularly those focused on:
- Broiler chicken production
- Egg-laying operations
- Small to medium-scale poultry farming

## Technical Specifications
- **Platform:** WordPress with WooCommerce
- **Design Philosophy:** Lightweight, responsive, modern aesthetics
- **Initial Authentication:** Not required for MVP phase
- **Shipping Rules:** Orders above 50kg qualify for shipping; smaller orders are pickup only
- **Approach:** Building a functional MVP first with plans to iterate and expand

## Included Markdown Files
The project includes several markdown (.md) files that should be used as follows:

### 1. sample-product-descriptions.md
This file contains detailed product descriptions for the initial inventory, including:
- Equipment items (feeders, nesting boxes, heat lamps)
- Feed products (starter crumble, layer pellets)
- Medication and supplements

**How to use this file:**
- Use these descriptions as templates when setting up the product catalog
- Maintain the format and structure of descriptions for consistency
- Replace placeholder image references with actual product images
- Adapt pricing as needed based on market conditions

### 2. educational-content.md
This file provides four comprehensive educational articles about chicken farming:
- Beginner's Guide to Raising Broiler Chickens
- Maximizing Egg Production
- Disease Prevention in Poultry
- Seasonal Care for Chicken Flocks

**How to use this file:**
- Create a "Resources" or "Learning Center" section on the website
- Format each article as a separate page or post
- Use these articles to establish expertise and provide value to customers
- Link to relevant products within the educational content when appropriate

## Implementation Instructions
1. Set up WordPress with WooCommerce and a lightweight theme
2. Configure basic store settings and create product categories
3. Add the initial product catalog using the descriptions from sample-product-descriptions.md
4. Create the educational content section using educational-content.md
5. Implement basic cart and checkout functionality
6. Configure shipping rules (50kg threshold for delivery vs. pickup)
7. Ensure mobile responsiveness and test on various devices

## Future Development (Post-MVP)
- User authentication and accounts
- Advanced inventory management
- Additional payment gateways
- Expanded product catalog
- Enhanced educational content
- Customer reviews and ratings

## Project Goals
- Create a simple yet functional ecommerce experience
- Establish credibility through educational content
- Build a foundation that can be easily expanded
- Provide a responsive design that works well on all devices
- Offer essential products for chicken farmers
